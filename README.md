# Passo - Ассоциативный менеджер паролей

Passo - это безопасный менеджер паролей с уникальной функцией генерации паролей на основе ассоциаций.

## Основные функции

- 🔐 Генерация паролей по ассоциативным словам
- 🗄️ Шифрованное локальное хранилище паролей
- 🏷️ Поддержка тегов и группировки
- 🔍 Быстрый поиск
- 🖥️ Автозаполнение в любом приложении
- 👀 Режим "Безопасный экран"
- 📊 Отслеживание использования паролей
- 💾 Защищенный экспорт/импорт данных

## Установка

1. Убедитесь, что у вас установлен Python 3.8 или выше
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/yourusername/passo.git
   cd passo
   ```
3. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/Mac
   # или
   .\venv\Scripts\activate  # Для Windows
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Использование

Запустите приложение:
```bash
python src/main.py
```

## Безопасность

- Все пароли хранятся в зашифрованном виде (AES-256)
- Поддержка двухфакторной аутентификации
- Автоматическая очистка буфера обмена
- Защита от просмотра через плечо
